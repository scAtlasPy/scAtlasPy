# Community and Contributions

scAtlasPy is an open-source project for atlas-scale single-cell omics analysis
and method development.

The progress of single-cell data analysis and cell atlas research depends on an
open ecosystem of datasets, computational methods, software tools, standards,
benchmarks, and experience from real biological studies. The reliability and
practical value of scAtlasPy will likewise grow through continued use,
evaluation, discussion, and contributions from the community.

We welcome researchers, software developers, method developers, and users of
cell atlas data to participate in the continued development of scAtlasPy.

## Contributing to scAtlasPy

Contributions can take many forms, including:

- reporting bugs or unexpected behavior;
- sharing requirements from real single-cell and cell atlas projects;
- suggesting improvements to workflows, interfaces, and interoperability;
- adapting existing single-cell methods to scAtlasPy;
- developing new analysis or visualization capabilities;
- contributing tests, benchmarks, and performance improvements;
- improving tutorials, API documentation, and reproducible examples;
- discussing data models and computational interfaces for future atlas-scale
  methods.

A contribution does not need to begin with a complete implementation. A clear
description of a use case, limitation, or proposed improvement can already help
guide the development of scAtlasPy and the broader cell atlas analysis
ecosystem.

Before making a substantial change, we recommend opening an issue to discuss
the intended use case and implementation direction with the maintainers.
