# Release Notes

This page records user-visible changes to scAtlasPy across releases.

The current documentation corresponds to the development version of scAtlasPy.
Public interfaces, default behavior, and stored outputs may still change before
the first stable release.

```{important}
For reproducible analyses, use the documentation that corresponds to the
installed scAtlasPy version. Development documentation may describe changes
that have not yet been included in a formal release.
```

## Unreleased

scAtlasPy is currently preparing its initial public release.

Current development focuses include:

- atlas-scale preprocessing and analysis workflows backed by persistent
  `.sasql` storage;
- query-based, streaming, and minibatch access to expression data;
- interoperability with in-memory single-cell methods through selected AnnData
  subsets;
- public APIs for preprocessing, dimensionality reduction, clustering,
  visualization, and custom method development;
- documentation covering installation, tutorials, API reference,
  cross-platform workflows, and architecture.

The exact public API and release contents will be finalized before the initial
version is published.
